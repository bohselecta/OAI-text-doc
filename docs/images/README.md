# Image provenance

These images are captured by `tests/browser.py` from the implemented custom element and actual document service, not generated concept art. The local run uses an explicitly recorded in-memory transport harness because the managed browser blocks navigation. Native CI recaptures the same states through ordinary navigation before repository delivery.

`document-draft.png`, `document-proposal.png`, `document-publish-blocked.png`, `document-publish.png`, `document-spaces.png`, `document-mobile.png`, and `document-light.png` cover representative working states. Rehearsal is visibly labeled and never shown as a live model or completed semantic review. Random document IDs and source hashes are local fixture values, not personal user data.
